Takes type and title of movie as input.
From there prints out a few sentences based on the type you chose.
Shows how Polymorphism works, where you set it off with the Movie object, but in reality create a new type object, say Adventure which you use without needing to know how it works.
It's a design pattern called Factory Method, basically the idea is to create objects in the superclass but delegate the actual instantiation to the subclasses.
